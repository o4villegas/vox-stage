- **Zero application code exists.** The tree is `CLAUDE.md`, `docs/`, `spikes/`, one
  Pages workflow. The MVP is milestones M1–M6 (`docs/ROADMAP.md`); M1 alone — repo

  phone" — is estimated at **4–5 sessions** in `docs/M1-PLAN.md` §7, and M1 has not been
  approved to build (rule 1).
- **Phase 0 is not closed.** S2's cold-start gate is still unmeasured, and S3's thresholds
  are still unratified. The working agreement is Phase 0 exit → M1 go.
- **Two of the three credentials granted today cannot be exercised from this
  environment.** `api.cloudflare.com` and `api.resend.com` are both denied by the
  sandbox's egress policy (HTTP 403 on CONNECT, 7 of 7 attempts each). The Cloudflare
  token and the Resend key are therefore present but **unverified**. Only RunPod works
  from here.

What *is* achievable today, in order of value: **close S2** (the last Phase 0 blocker),
write the **Phase 0 exit report**, get the **M1 go**, and — if the deploy path in §4 is
settled — start M1 scaffolding. The honest calendar for "sign in on a phone" is days, and
for "upload a song, sing it synced, get scored" it is weeks.
